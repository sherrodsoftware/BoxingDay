# Contributing to Boxing Day

Thanks for your interest in improving Boxing Day.

## Before You Start

- Search existing issues before opening a new one.
- Open an issue to discuss substantial features or behavior changes before
  investing in an implementation.
- Never include Jamf Pro URLs, client IDs, client secrets, package contents,
  or other organization-specific data in issues, pull requests, screenshots,
  or test fixtures.

## Pull Requests

- Keep changes focused and include tests when practical.
- Run the full test suite in Xcode before submitting a pull request.
- Describe the problem, the solution, and how you tested it.

By submitting a contribution, you confirm that you have the right to submit it
and agree to license it under the repository's MIT License.
